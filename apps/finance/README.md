# Florin (web) — Archived

**Status: archived, 2026-07-29.** Not under active development.

Florin's direction shifted to a local-first, native Mac/iPhone/iPad app built on
`warehouse`'s local SQLite database, with no server-side system of record. See
the current brief: `finanace.personal.md` in the Ponti Studios vault
(`ponti-studios/projects/_ideas/`).

This app (server-side Postgres, Plaid via `packages/finance`) is not part of
that thesis going forward. It's left in place — data and code intact — rather
than deleted, since it may still hold real historical data worth referencing.
No new feature work should land here; direct it at the native app instead.
